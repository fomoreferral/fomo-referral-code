## How to enter Fomo referral code DEAL

1. On the phone you will trade on, open **fomo.family/r/deal** before you create an account.
2. Install the Fomo app, or open it if it is already installed. Do not sign in to an older Fomo account: an
   account that already exists keeps the referrer it has.
3. Create the account with your **Apple ID** or **Google Account**. Keep using the same one later; a different
   login creates a separate account, and the code stays on the first one.
4. If the sign-up screen shows a referral code box, type **DEAL**.
5. After your first standard trade, check the fee line: **0.45%** means the referral discount is on.

## Already signed up without a code?

There is no field to add a referral code after sign-up. One exception: if you opened fomo.family/r/deal before
signing up and your standard trades still show 0.50% (no referrer recorded), Fomo support can attach DEAL to your
account. In the app go to Profile, Settings, Help and Support, then Contact Support, and ask to be attached to the
code DEAL. A referrer that is already recorded cannot be changed.

## Where the cashback comes from

Fomo pays the owner of a referral code 25% of the trading fees of the users who joined with it. The DEAL code owner
passes half of that, 12.5% of your fees, back to you in USDC. Fomo itself pays no cashback; the 10% discount is
Fomo's and is the same for every referral code.

## Good to know

- A Fomo referral code is a Fomo username. DEAL is one of them.
- Codes that promise more than 10% off (some say 100%) are not real: Fomo's referral discount is 10%, the same
  for every code.
- On Solana, Fomo covers gas. On Base, BNB Chain, Monad, Robinhood Chain, Ethereum and Arc you pay network fees on
  top of Fomo's fee.
- Select major tokens cost 0.05% per trade.
