## How to check it worked

Look at the fee line on your first standard trade. **0.45%** means the referral discount is on; 0.50% means no
referrer was recorded. If you opened the link first and nothing was recorded, contact support in the app
(Profile, Settings, Help and Support, Contact Support) and ask to be attached to `DEAL`. A referrer that is
already recorded cannot be changed.

## Good to know

- A Fomo referral code is a Fomo username. Invite code, promo code and referral code all mean the same box.
- Fomo's referral discount is 10%, the same for every code. Pages promising 50% or 100% off Fomo fees are not
  describing Fomo's program. What a code can add is cashback from its owner, which is what DEAL does.
- Fomo covers gas on Solana. On Base, BNB Chain, Monad, Robinhood Chain, Ethereum and Arc you pay network fees on
  top of Fomo's fee. Select major tokens cost 0.05% a trade.
